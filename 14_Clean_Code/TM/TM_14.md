## Tugas
Dari dua kode di bawah ini, mana yang kamu ingin cari masalahnya dan perbaiki di tengah-tengah malam, katakanlah jam 1 malam? Mengapa?
```
function processUser(user) {
  if (user) {
    if (user.isActive) {
      if (user.hasPermission) {
        return doSomething(user)
      }
    }
  }
  return null
}
```

```
function processUser(user) {
  if (!isValidCandidate(user)) return null;
  return doSomething(user);
}

function isValidCandidate(user) {
  return user && user.isActive && user.hasPermission;
}
```

## Deskripsi Program
Aku pilih **kode kedua** karena jauh lebih gampang dibaca dan dicari bugnya, apalagi kalau udah jam 1 malam dan mata udah mau nutup sendiri.
 
### Kenapa Bukan Kode Pertama?
Kode pertama itu punya tiga lapis `if` yang bersarang. Jadi buat ngerti alurnya, otak harus terus lacak "sekarang aku ada di kondisi yang mana sih?" dan itu capek banget kalau lagi ngantuk. Belum lagi kalau salah hitung kurung kurawal `}` nya, langsung pusing.
 
### Kenapa Kode Kedua Lebih Enak?
Kode kedua itu cuma 2 baris di fungsi utamanya. Sekali baca langsung ngerti:
- Kalau user-nya ga valid → langsung `return null`, selesai
- Kalau valid → lanjut ke `doSomething(user)`
Selain itu, logika validasinya dipisah ke fungsi sendiri namanya `isValidCandidate()`. Jadi kalau ada bug di bagian validasi, langsung tau harus lihat ke fungsi itu ga perlu korek-korek isi fungsi utama dulu.
 
Nama fungsinya juga udah jelas banget, `isValidCandidate` = "apakah user ini kandidat yang valid?" ga perlu komentar tambahan buat ngerti maksudnya.
